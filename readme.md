# LAYER 03: PSYCHE
PSYCHE (pronounced "pa shuu ke") is a personal fork of ACCELA.
  
 On top of ACCELA's existing features, PSYCHE adds:

- Discord login support
- Automatic Hubcaps Manifest API key generation
- Automatic GreenLuma installation*
- Updated GreenLuma implementation*

*Only available on Windows
# Running

## Linux (Automatic)
Run: `curl -fsSL https://raw.githubusercontent.com/uncreativeCultist/layer03/refs/heads/main/enter-the-wired | bash`  
Note: If PSYCHE fails to launch, make sure your distro's package for tkinter is installed.
## Windows (Automatic)
1. Download the latest release
2. Extract the zip into a new folder
3. Read `!README.txt`
4. Run `ACCELA.exe`
## Running from source	
This supports Windows, Linux, and (to a limited extent), MacOS.

### Prerequisites
1. [Python 3.14](https://www.python.org/downloads/release/python-31410/) (ymmv with newer/older versions)
2. [Git](https://git-scm.com/)
3. If on Linux or MacOS, create and enter a [venv](https://www.w3schools.com/python/python_virtualenv.asp).
4. A copy of PSYCHE's source code.
This can be obtained via git, or via `Code` -> `Download Zip` on the Github page.

---
### Installation
1. Read `!README.txt`
2. Enter a terminal
3. Enter to the source folder, then run `pip install -r requirements.txt`
4. Run `main.py` using Python
